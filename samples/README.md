# Sample data

Synthetic inputs for demos and tests: a sample BRD and meeting transcript, a small fixture
repository, and the scripted coding scenario used when no code model is available. Everything
here is labeled as sample data in the database and the UI.

`repositories/sample-task-service-go` is the same service in Go. It has no scripted scenario and no
shipped acceptance suite, so delivering it needs a code model (see `docs/operations/models.md`).
